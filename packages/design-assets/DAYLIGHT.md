# Daylight native assets

daylight.svg and orbit.svg are original flat vector illustrations authored for WakeMe. Both apps
now draw their scene in code (`DawnScene`, `DawnArc`), so these two files are provenance only.
Reference screens inform layout and palette; their mascots, photos and icons are not bundled.
Manrope is bundled unmodified from google/fonts, under the included OFL 1.1 license.
Legacy generated 3D assets remain as provenance but are no longer used by the product UI.
