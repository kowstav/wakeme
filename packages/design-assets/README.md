# WakeMe native illustrations

Generated for this project on 30 October 2026 with the built-in image-generation tool, following the owner's request for a visual-led modern app. Original transparent PNGs are kept here and copied unchanged into Android drawable-nodpi and the iOS Illustrations asset catalog. They have no runtime network dependency.

The morning illustration communicates alarms and dawn through a forest clock, lime sun, clouds and a duck. The companion connection illustration communicates friends. These are decorative, not real alarm times, metrics or interactive controls. Screen labels and account/permission decisions remain native and accessible. Do not bake screen text into illustrations or flatten them into UI screenshots.

Palette: the existing forest/lime identity, ivory, sky and restrained peach. Materials: soft sculptural ceramic/resin. Dribbble is a concept reference; no third-party shot or app artwork is copied. Transparent alpha must be preserved, with native semantic surfaces behind it for light and dark appearances.

Google authentication uses the official unmodified G asset from https://developers.google.com/static/identity/images/g-logo.png and the unmodified Google Sans font from https://github.com/google/fonts/tree/main/ofl/googlesans. Its OFL license is bundled at Android assets/licenses/GoogleSans-OFL.txt. The native white/dark button is a vendor-brand exception to WakeMe’s lime controls, following https://developers.google.com/identity/branding-guidelines.
