# Legal drafts

**These are working drafts for counsel, not legal advice and not approved text.** They
describe what the code in this repository actually does (2026-10-19) so a lawyer can turn
them into the published policy and terms. Nothing here may be published until reviewed.

Decisions the owner must make first (doc 04 §18):

- Legal entity, registered address and contact for privacy requests (and a DPO or EU/UK
  representative if required).
- Launch region(s). The pilot assumption is adults 18+, one primary region, invite-only.
- Hosting and processor contracts (Supabase region, object storage, push, AI, billing) and
  the transfer mechanism for each.
- Final retention periods (the code uses proposals; see the privacy policy draft, §6).

Keep these drafts in sync with code changes that alter data collection: the store privacy
labels (`docs/store`) and these drafts must change in the same pull request.
