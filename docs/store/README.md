# Store submission drafts

Drafts for the App Store and Google Play listings, privacy disclosures, permission
declarations and reviewer notes, matching the code on 2026-10-19. **Not submitted**;
submission needs the owner's developer accounts, signing and authorization (CLAUDE.md:
publishing requires explicit owner authorization). Update these in the same change as any
code that alters data collection, permissions or SDKs.

- [listing.md](listing.md): name, subtitle, description, keywords, screenshots plan.
- [app-store.md](app-store.md): App Privacy labels, age rating, capabilities, review notes.
- [google-play.md](google-play.md): Data safety, permission declarations, content rating,
  testing requirement, review notes.
